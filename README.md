# Nexus Lounge

> Part of the [Cyberspace Framework](https://github.com/zerosquaredio/cyberspace-framework).
> See that repo for the framework's goals and how its projects fit together.

**Nexus Lounge** is a terminal-style BBS network that uses the
[AT Protocol](https://atproto.com) for identity: callers log in to boards with
their Bluesky (or other AT) accounts. It is the framework's first piece.

This repo holds its specs and plans, and later the hub's code:

- [docs/README.md](docs/README.md): overview, architecture, and an index of
  the design docs
- [docs/development_plan.md](docs/development_plan.md): features, milestones,
  and progress

The BBS work itself is on the
[zerosquaredio/enigma-bbs](https://github.com/zerosquaredio/enigma-bbs/tree/atproto-login)
fork of [ENiGMA½](https://github.com/NuSkooler/enigma-bbs), branch
`atproto-login`.
