# Contributing

Improvements are welcome, and so are BBSes and hubs built on this work, open
or closed. If you run your own version and fix or improve something, please
send it back.

Issues and pull requests go here for the BBS network and hub specs, and
later the hub's code. How to contribute, which repo a change belongs in, and
licensing are covered in the
[Cyberspace Framework's CONTRIBUTING.md](https://github.com/zerosquaredio/cyberspace-framework/blob/main/CONTRIBUTING.md).

In short: code is [BSD 2-Clause](LICENSE), docs are
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), and contributions
are accepted under the same terms.
